# PodFlow Player

A lightweight React podcast discovery and playback app.

## Local Development

Install dependencies:

```sh
npm install
```

Start the Vite dev server:

```sh
npm run dev
```

Build for production:

```sh
npm run build
```

Preview the production build locally:

```sh
npm run preview
```

## Deployment

This app is configured for Vercel. Vercel should install dependencies, run
`npm run build`, and serve the generated `dist` directory.
